## 1. Propriedades do Contêiner de Grid

| Propriedade | Sintaxe Comum | Descrição |
| :--- | :--- | :--- |
| `display` | `grid \| inline-grid` | Habilita o contexto de formatação bidimensional |
| `grid-template-columns` | `repeat(3, 1fr) \| 200px 1fr` | Define as larguras explícitas das colunas |
| `grid-template-rows` | `auto 1fr auto \| repeat(4, 100px)` | Define as alturas explícitas das linhas |
| `grid-template-areas` | `"header header" "sidebar main"` | Mapeia o layout em matriz ASCII |
| `gap` | `var(--space-m) \| 1rem 2rem` | Espaçamento entre faixas (`row-gap` e `column-gap`) |
| `grid-auto-flow` | `row \| column \| dense` | Direção do fluxo implícito e empacotamento denso |
| `grid-auto-rows` | `minmax(150px, auto)` | Tamanho padrão de linhas criadas dinamicamente |
| `grid-auto-columns` | `200px` | Tamanho padrão de colunas criadas dinamicamente |

## 2. Alinhamento no Grid (Box Alignment)

| Propriedade | Eixo | Alvo | Valores Comuns |
| :--- | :--- | :--- | :--- |
| `justify-items` | Inline (Horizontal) | Células | `stretch` (default), `start`, `center`, `end` |
| `align-items` | Block (Vertical) | Células | `stretch` (default), `start`, `center`, `end` |
| `place-items` | Ambos | Células | `center` (alinha ambos os eixos no centro) |
| `justify-content` | Inline (Horizontal) | O Grid inteiro | `start`, `center`, `end`, `space-between`, `space-evenly` |
| `align-content` | Block (Vertical) | O Grid inteiro | `start`, `center`, `end`, `space-between`, `space-around` |
| `place-content` | Ambos | O Grid inteiro | `center space-between` |

## 3. Propriedades dos Itens (Filhos Diretos)

```css
.item {
  /* Coordenadas de Linha */
  grid-column: 1 / 3;        /* Começa na linha 1 e termina na linha 3 */
  grid-column: span 2;       /* Estende por 2 faixas */
  grid-column: 1 / -1;       /* Ocupa a largura total da primeira à última linha */

  grid-row: 2 / span 3;      /* Começa na linha 2 e se estende por 3 linhas */

  /* Áreas Nomeadas */
  grid-area: header;

  /* Alinhamento Individual */
  justify-self: end;         /* Alinha este item específico no final horizontal da célula */
  align-self: center;        /* Centraliza este item específico verticalmente */
  place-self: center end;    /* Shorthand align-self + justify-self */
}
```

## 4. As Fórmulas Sagradas

```css
/* 1. Grade Intrínseca Sem Media Queries */
.grid-responsive {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(min(100%, 250px), 1fr));
  gap: var(--space-m);
}

/* 2. Sobreposição de Camadas Sem Absolute */
.stack-layer {
  display: grid;
}
.stack-layer > * {
  grid-area: 1 / 1;
}

/* 3. Subgrid Perfeito para Cards */
.card-item {
  grid-row: span 3;
  display: grid;
  grid-template-rows: subgrid;
}
```
