## 1. Conceito

No Flexbox, o alinhamento é direto:

- **Eixo Principal (Main Axis)**: Governado por `justify-content`
- **Eixo Transversal (Cross Axis)**: Governado por `align-items` (e overrides individuais com `align-self`)

```css
.container {
  display: flex;
  justify-content: space-between; /* Distribui no eixo principal */
  align-items: center;            /* Centraliza no eixo transversal */
  gap: var(--space-m);
}
```

## 2. A Mágica Secreta do Flexbox: `margin: auto`

Quase todos os desenvolvedores usam `justify-content: space-between` quando querem colocar a logo à esquerda e o botão de login à direita.

Porém, e se a barra de navegação contiver:
1. Logo
2. Link "Home"
3. Link "Docs"
4. Link "Preços"
5. *(Espaço vazio flexível)*
6. Botão "Entrar"
7. Botão "Criar Conta"

Se você usar `justify-content: space-between`, todos os links intermediários ficarão espalhados e distantes uns dos outros!

A solução mais elegante, canônica e nativa do CSS: **Margens Automáticas (`margin: auto`) em Flexbox**:

```css
.navbar {
  display: flex;
  align-items: center;
  gap: var(--space-s);
}

/* O elemento de login absorve TODO o espaço livre restante à sua esquerda! */
.navbar-login {
  margin-inline-start: auto;
}
```

<Callout type="info" title="Como margin: auto Opera no Flexbox">
  No modelo de formatação Flexbox, uma margem definida como `auto` tem precedência absoluta sobre `justify-content`. Ela absorve 100% do espaço restante disponível naquela direção e empurra os elementos subsequentes para a extremidade oposta.
</Callout>

## 3. Centralização Vertical Perfeita com `margin: auto`

Não apenas na horizontal: em um contêiner flexível com altura definida, aplicar `margin: auto` em um filho centraliza o elemento **perfeitamente em ambos os eixos simultaneamente**:

```css
.parent {
  display: flex;
  min-block-size: 300px;
}

.child {
  /* Centralizado perfeitamente na horizontal e na vertical! */
  margin: auto;
}
```

## 4. `align-items: stretch` vs Alinhamento de Linhas de Texto

Por padrão, `align-items` tem o valor `stretch`. Isso faz com que todos os filhos tenham a mesma altura (o que é excelente para cards ou colunas).

Porém, se você estiver alinhando um ícone e um texto, ou títulos com tamanhos de fonte diferentes na mesma linha, `align-items: center` ou `align-items: baseline` são cruciais:

```css
.metric-row {
  display: flex;
  /* Alinha os textos pela linha de base tipográfica, mesmo com tamanhos de fonte discrepantes */
  align-items: baseline;
  gap: var(--space-xs);
}

.metric-number { font-size: var(--step-4); font-weight: bold; }
.metric-unit   { font-size: var(--step-0); color: var(--color-fg-muted); }
```

</style>`}

## 6. Boas Práticas

1. **Use `margin-inline-start: auto` para ações à direita**: O padrão definitivo para cabeçalhos e toolbars.
2. **Utilize `align-items: baseline` para textos adjacentes**: Garante harmonia visual entre números grandes e unidades pequenas.
3. **Use `gap` em vez de margens nos filhos**: Mantém o componente desacoplado e reutilizável.
