## 1. Conceito

O **CSS Flexbox** (Flexible Box Layout) é um modelo de layout projetado para organizar, distribuir e alinhar elementos ao longo de **um único eixo de cada vez**: ou horizontalmente (em linha) ou verticalmente (em coluna).

Ao contrário do CSS Grid (onde o contêiner impõe uma grade bidimensional rígida e os filhos devem se encaixar nela), no Flexbox **o conteúdo interno dos filhos dita o tamanho das caixas**, e o algoritmo flexível distribui o espaço restante ou absorve o encolhimento.

```
       Eixo Principal (Main Axis) ────►
     ┌──────────────┬──────────────────┬──────────────┐ ▲
     │  Flex Item 1 │   Flex Item 2    │  Flex Item 3 │ │ Eixo Transversal
     │  (conteúdo)  │ (conteúdo maior) │  (conteúdo)  │ │ (Cross Axis)
     └──────────────┴──────────────────┴──────────────┘ ▼
```

<Callout type="info" title="Axioma Unidimensional">
  Se você precisa alinhar elementos ao longo de uma linha (como botões, tags ou itens de navegação), use Flexbox. Se você precisa coordenar simultaneamente linhas E colunas, use CSS Grid.
</Callout>

## 2. A Direção do Fluxo (`flex-direction`)

O eixo principal é determinado por `flex-direction`:

- `row` (padrão em LTR): Da esquerda para a direita.
- `row-reverse`: Da direita para a esquerda.
- `column`: De cima para baixo (ideal para pilhas verticais e cartões).
- `column-reverse`: De baixo para cima.

Quando você altera `flex-direction: column`, **tudo se inverte**:
- O Eixo Principal passa a ser o eixo vertical.
- O Eixo Transversal passa a ser o eixo horizontal.
- `justify-content` agora governa o alinhamento vertical.
- `align-items` agora governa o alinhamento horizontal.

## 3. O Comportamento Padrão dos Filhos

Ao transformar um elemento em `display: flex`:
1. Os filhos diretos se tornam *flex items*.
2. Os itens são dispostos em uma única linha (`flex-wrap: nowrap`).
3. Os itens começam alinhados no início (`justify-content: flex-start`).
4. Os itens **esticam para ter a mesma altura** no eixo transversal (`align-items: stretch`).
5. Os itens encolhem para não estourar a tela se necessário (`flex-shrink: 1`), mas não crescem sozinhos (`flex-grow: 0`).

## 5. Boas Práticas

1. **Use `gap` no Flexbox**: Nunca mais adicione `margin-right` com pseudo-classes `:last-child` nos filhos.
2. **Entenda a inversão de eixos em `column`**: Lembre-se que `justify-content` atua no eixo da direção escolhida.
3. **Respeite o tamanho intrínseco**: Deixe botões e badges assumirem sua largura natural a partir do texto.
