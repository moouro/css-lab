### Problema
Evitar que o rodapé flutue no meio da tela em monitores grandes ou em páginas com parágrafos curtos, sem usar `position: fixed` (que cobriria o conteúdo).

### Código

```css
body {
  display: flex;
  flex-direction: column;
  min-block-size: 100dvh;
  margin: 0;
}

main {
  /* Absorve todo o espaço vertical disponível, empurrando o footer */
  flex: 1 0 auto;
}

footer {
  flex-shrink: 0;
}
```
