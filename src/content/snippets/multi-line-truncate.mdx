### Problema
`text-overflow: ellipsis` clássico só funciona em uma única linha rígida com `white-space: nowrap`.

### Código

```css
.truncate-3-lines {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

/* Suporte à nova especificação padrão quando disponível */
@supports (line-clamp: 3) {
  .truncate-3-lines {
    display: block;
    line-clamp: 3;
    overflow: hidden;
  }
}
```
