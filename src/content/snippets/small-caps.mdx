### Problema
Usar `text-transform: uppercase; font-size: 0.8em;` gera letras maiúsculas artificiais com espessura de traço mais fina do que o restante da fonte, parecendo amador.

### Código

```css
.lead-caption,
.kicker {
  /* Ativa os glifos OpenType desenhados pelo designer da fonte */
  font-variant-caps: all-small-caps;
  letter-spacing: 0.08em;
  font-weight: 600;
}
```
