### Problema
Barras de rolagem cinzas nativas quebram a estética de carrosséis de produtos e reels horizontais modernos.

### Código

```css
.scrollbar-none {
  /* Firefox */
  scrollbar-width: none;
  /* IE and Edge */
  -ms-overflow-style: none;
}

/* Chrome, Safari, Edge moderno */
.scrollbar-none::-webkit-scrollbar {
  display: none;
}
```
