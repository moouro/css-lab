### Problema
Eliminar as 4 linhas legadas de `position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%)` que causavam desfoque subpixel em monitores de baixa resolução.

### Código

```css
.center-box {
  display: grid;
  place-items: center;
  min-block-size: 100%;
}
```
