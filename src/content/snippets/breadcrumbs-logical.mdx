### Problema
Inserir barras `/` ou setas `>` no próprio HTML é lido por leitores de tela como palavras soltas ("barra", "maior que"), incomodando usuários cegos.

### Código

```css
.breadcrumb-list {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  gap: var(--space-2xs);
  list-style: none;
  padding: 0;
  margin: 0;
  font-size: var(--step--1);
}

.breadcrumb-item + .breadcrumb-item::before {
  content: "/";
  color: var(--color-fg-muted);
  margin-inline-end: var(--space-2xs);
  user-select: none;
  aria-hidden: true;
}

.breadcrumb-item a {
  color: var(--color-fg-muted);
  text-decoration: none;
}

.breadcrumb-item a:hover {
  color: var(--color-fg);
  text-decoration: underline;
}

.breadcrumb-item[aria-current="page"] {
  color: var(--color-fg);
  font-weight: 600;
}
```
