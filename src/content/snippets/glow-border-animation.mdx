### Problema
Animar o ângulo de rotação de um `conic-gradient` no CSS puro sem criar divs duplicadas girando com `transform: rotate()`.

### Código

```css
@property --border-angle {
  syntax: "<angle>";
  inherits: false;
  initial-value: 0deg;
}

.glow-card {
  --border-angle: 0deg;
  position: relative;
  background: var(--color-bg-surface);
  border-radius: var(--radius-md);
  padding: var(--space-m);
}

.glow-card::before {
  content: "";
  position: absolute;
  inset: -1px;
  border-radius: inherit;
  padding: 1px;
  background: conic-gradient(
    from var(--border-angle),
    transparent 20%,
    var(--color-accent) 50%,
    transparent 80%
  );
  -webkit-mask: linear-gradient(#fff 0 0) content-box, linear-gradient(#fff 0 0);
  -webkit-mask-composite: xor;
  mask-composite: exclude;
  pointer-events: none;
  animation: spin-glow 4s linear infinite;
}

@keyframes spin-glow {
  to {
    --border-angle: 360deg;
  }
}
```
