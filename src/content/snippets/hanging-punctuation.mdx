### Problema
Quando uma citação ou parágrafo começa com aspas (`"“"`), o glifo da aspa empurra a primeira letra para a direita, quebrando a linha visual reta da margem esquerda do texto.

### Código

```css
blockquote, p {
  /* Pendura aspas e travessões para fora da caixa de alinhamento */
  hanging-punctuation: first last;
}
```
