### Problema
Eliminar múltiplos breakpoints para títulos que saltam de tamanho de forma desagradável.

### Código

```css
:root {
  /* Escala Fluida Harmônica (Major Third - 1.25) */
  --step--1: clamp(0.83rem, 0.77rem + 0.31vw, 1rem);
  --step-0:  clamp(1rem, 0.91rem + 0.43vw, 1.25rem);      /* Corpo */
  --step-1:  clamp(1.2rem, 1.07rem + 0.63vw, 1.56rem);    /* Subtítulo */
  --step-2:  clamp(1.44rem, 1.26rem + 0.89vw, 1.95rem);   /* H3 */
  --step-3:  clamp(1.73rem, 1.48rem + 1.24vw, 2.44rem);   /* H2 */
  --step-4:  clamp(2.07rem, 1.73rem + 1.7vw, 3.05rem);    /* H1 */
}

h1 { font-size: var(--step-4); line-height: 1.15; }
h2 { font-size: var(--step-3); line-height: 1.2; }
p  { font-size: var(--step-0); line-height: 1.6; max-inline-size: 65ch; }
```
