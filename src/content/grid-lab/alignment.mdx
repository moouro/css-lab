## 1. Conceito

O alinhamento no CSS moderno foi unificado pela especificação **CSS Box Alignment Module**. No CSS Grid, existem dois eixos fundamentais e dois níveis de controle:

### Os Dois Eixos:
- **Eixo Inline (Horizontal)**: Controlado pelas propriedades com prefixo `justify-*`.
- **Eixo Block (Vertical)**: Controlado pelas propriedades com prefixo `align-*`.

### Os Dois Níveis:
- **Itens dentro das suas células**: `justify-items` / `align-items` (e overrides individuais com `justify-self` / `align-self`).
- **O Grid inteiro dentro do contêiner**: `justify-content` / `align-content`.

## 2. A Tabela Mestra de Alinhamento

| Propriedade | Eixo | O que movimenta? | Valores Comuns |
| :--- | :--- | :--- | :--- |
| `justify-items` | Inline (Horizontal) | Todos os itens dentro de cada célula individual | `stretch` (default), `start`, `center`, `end` |
| `align-items` | Block (Vertical) | Todos os itens dentro de cada célula individual | `stretch` (default), `start`, `center`, `end` |
| `justify-content` | Inline (Horizontal) | As faixas do grid como um bloco dentro do contêiner | `start`, `center`, `end`, `space-between`, `space-evenly` |
| `align-content` | Block (Vertical) | As faixas do grid como um bloco dentro do contêiner | `start`, `center`, `end`, `space-between`, `space-around` |
| `justify-self` | Inline (Horizontal) | O item específico na sua célula | `stretch`, `start`, `center`, `end` |
| `align-self` | Block (Vertical) | O item específico na sua célula | `stretch`, `start`, `center`, `end` |

## 3. O Shorthand Mágico: `place-items: center`

A forma mais rápida, elegante e definitiva de centralizar qualquer elemento nos dois eixos em toda a história da web:

```css
.center-everything {
  display: grid;
  place-items: center; /* Equivalente a: align-items: center + justify-items: center */
}
```

Duas linhas de código. Sem truques de `position: absolute`, sem `transform: translate(-50%, -50%)`, sem cálculos manuais.

## 4. `*-items` vs `*-content`: A Diferença Fundamental

Um dos pontos que mais confundem desenvolvedores:
- Use `justify-items` quando você quiser controlar a largura e o alinhamento **do conteúdo de cada célula** (por exemplo, impedir que botões estiquem para 100% da largura da célula usando `justify-items: start`).
- Use `justify-content` quando a soma das suas colunas for menor do que o contêiner (por exemplo, 3 colunas de 100px dentro de um contêiner de 800px) e você quiser centralizar o **bloco do grid inteiro** na tela: `justify-content: center`.

## 6. Boas Práticas

1. **Use `place-items` e `place-content`**: Shorthands tornam a folha de estilos mais concisa e expressiva.
2. **Defina `justify-items: start` em grids de cards com botões**: Impede que botões de ação ou links estiquem artificialmente até a borda do card, a não ser que isso seja desejado.
3. **Utilize `*-self` para quebrar a regra pontualmente**: Um único item pode ter `align-self: end` sem afetar toda a grade.
