## 1. Conceito

Durante anos, desenvolvedores escreveram dezenas de linhas de JavaScript e manipularam classes CSS para criar o efeito de **Acordeão** (perguntas frequentes, listas retráteis, menus colapsáveis).

A plataforma web padronizou isso nativamente através dos elementos HTML:
- `<details>`: O contêiner de expansão.
- `<summary>`: O cabeçalho clicável que atua como gatilho.

Não é necessário nenhum JavaScript. O navegador gerencia a abertura, o fechamento, o foco por teclado (`Tab`, `Enter`, `Espaço`) e o anúncio para leitores de tela sem uma única dependência!

## 2. A Nova Pseudo-Elemento `::details-content` (Baseline 2024)

Historicamente, o maior motivo pelo qual os desenvolvedores abandonavam o `<details>` nativo era a **impossibilidade de animar a altura suavemente**. Quando o usuário clicava, o conteúdo aparecia instantaneamente com um salto brusco.

A nova especificação introduziu o pseudo-elemento **`::details-content`** e a propriedade `interpolate-size: allow-keywords`:

```css
:root {
  /* Habilita animação suave de height: auto nativa no CSS! */
  interpolate-size: allow-keywords;
}

details {
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
  background-color: var(--color-bg-surface);
  overflow: hidden;
  transition: border-color var(--duration-fast) ease;
}

/* O gatilho clicável */
summary {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: var(--space-s) var(--space-m);
  font-weight: 600;
  cursor: pointer;
  user-select: none;
  list-style: none; /* Remove o triângulo padrão do navegador */
}

/* Remove o marcador nativo no Safari/WebKit */
summary::-webkit-details-marker {
  display: none;
}

/* Ícone de seta personalizado */
summary::after {
  content: "›";
  font-size: 1.25em;
  line-height: 1;
  transition: transform var(--duration-fast) ease;
}

/* Gira a seta quando o acordeão estiver aberto */
details[open] summary::after {
  transform: rotate(90deg);
}

/* Animação suave do conteúdo nativo */
details::details-content {
  opacity: 0;
  block-size: 0;
  overflow-y: clip;
  transition: content-visibility var(--duration-normal) allow-discrete,
              opacity var(--duration-normal) ease,
              block-size var(--duration-normal) ease;
}

details[open]::details-content {
  opacity: 1;
  block-size: auto;
}
```

<Callout type="info" title="Zero JavaScript, 100% Animação Fluida">
  Com `::details-content` e `interpolate-size: allow-keywords`, a transição de altura para `auto` agora ocorre diretamente no motor de renderização do navegador, sem nenhum cálculo de `scrollHeight` via JS!
</Callout>

## 3. O Atributo `name` para Acordeões Exclusivos (Accordion Groups)

E se você quiser que abrir um acordeão **feche automaticamente todos os outros** da mesma seção?

Antes, isso exigia um loop de JavaScript. Agora, basta adicionar o atributo nativo **`name`**:

```html
<!-- Pertencem ao mesmo grupo: apenas um pode ficar aberto por vez! -->
<details name="faq-group">
  <summary>Como funciona a licença do projeto?</summary>
  <p>O projeto é 100% aberto e pessoal sob a licença MIT.</p>
</details>

<details name="faq-group">
  <summary>Quais navegadores são suportados?</summary>
  <p>Todos os navegadores modernos com suporte a CSS Baseline.</p>
</details>
```

## 5. Boas Práticas

1. **Sempre use `<summary>` como primeiro filho direto**: Qualquer outro elemento que não seja `<summary>` não funcionará como gatilho clicável.
2. **Utilize o atributo `name` para grupos exclusivos**: Elimine código JS de fechamento mútuo.
3. **Adicione `overflow-y: clip` ao animar**: Previne que o texto vaze enquanto a caixa cresce verticalmente.
