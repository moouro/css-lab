## 1. Conceito

Alinhar texto ao centro com `text-align: center` quebra a borda esquerda do bloco de leitura (*ragged edge*), forçando o olho a procurar o início de cada nova linha. O **Center** cria uma coluna centralizada horizontalmente no container, mantendo o alinhamento de texto natural e limitando a largura à **medida de leitura ideal** (cerca de 45 a 75 caracteres).

## 2. A Sutileza do Box-Sizing

Ao contrário de quase todos os elementos onde `box-sizing: border-box` é preferido, o **Center** do *Every Layout* adota `box-sizing: content-box`.

Por quê?
Se o container estivesse em `border-box` com `max-inline-size: 60ch`, qualquer padding interno adicionado reduziria a largura útil do texto, tornando a linha mais curta que a medida desejada. Com `content-box`, o padding atua como **gutter exterior** em viewports estreitas sem encolher o bloco de texto quando há espaço suficiente!

```css
.center {
  box-sizing: content-box;
  max-inline-size: var(--center-max, 65ch);
  margin-inline: auto;
  padding-inline: var(--center-gutter, var(--space-m));
}
```

<AntiPattern
  badCode={`/* Frágil: margens abreviadas resetam margens verticais */\n.center {\n  margin: 0 auto; /* destrói qualquer margin-top vinda de um Stack pai! */\n}`}
  goodCode={`/* Resiliente: propriedade lógica preserva margens verticais */\n.center {\n  margin-inline: auto;\n}`}

## 3. Centralização Intrínseca

Quando você ativa o modo `intrinsic`, o Center transforma-se em um contexto flexível em coluna para centralizar filhos menores (como botões de ação ou badges):

```css
.center[data-intrinsic] {
  display: flex;
  flex-direction: column;
  align-items: center;
}
```
