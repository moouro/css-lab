## 1. Conceito

Posicionar elementos fora do fluxo com `position: absolute` é perigoso porque desconecta o elemento do algoritmo padrão de medição do navegador. O **Imposter** é o padrão controlado para sobreposição deliberada: diálogos modais, banners de confirmação, popups e mensagens de carregamento.

## 2. A Fórmula com Propriedades Lógicas e translate

A abordagem moderna não usa `top`, `left` nem `transform: translate()` legado:

```css
.imposter {
  position: var(--imposter-position, absolute);
  inset-block-start: 50%;
  inset-inline-start: 50%;
  translate: -50% -50%;
}

.imposter[data-contain] {
  --imposter-margin: var(--space-s);
  overflow: auto;
  max-inline-size: calc(100% - (var(--imposter-margin) * 2));
  max-block-size:  calc(100% - (var(--imposter-margin) * 2));
}
```

<Callout type="tip" title="Por que a propriedade individual 'translate'?">
  A propriedade CSS individual `translate: -50% -50%` é amplamente suportada (Baseline) e evita sobrescrever ou competir com declarações de `scale` ou `rotate` na mesma regra, permitindo animações suaves e independentes!
</Callout>

<AntiPattern
  badCode={`/* Frágil: margens negativas com dimensões fixas obrigatórias */\n.dialog {\n  position: absolute;\n  left: 50%; top: 50%;\n  width: 400px; height: 300px;\n  margin-left: -200px; margin-top: -150px; /* Quebra se o texto crescer! */\n}`}
  goodCode={`/* Resiliente: algoritmo auto-adaptável */\n.imposter {\n  position: absolute;\n  inset-block-start: 50%;\n  inset-inline-start: 50%;\n  translate: -50% -50%;\n}`}
  explanation="O translate percentual calcula 50% das próprias dimensões do elemento em tempo de execução, adaptando-se a qualquer volume dinâmico de texto."
/>
