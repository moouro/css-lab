## 1. Conceito

Páginas de apresentação inicial (*splash screens*, heros ou capas de apresentação de slides) exigem que um elemento principal gravite para o centro da área visível, mantendo itens secundários (como uma barra de navegação no topo ou um botão "Saiba Mais" na base) ancorados nas bordas.

O **Cover** realiza essa composição de maneira tolerante a conteúdo dinâmico.

## 2. A Mecânica: min-block-size vs height: 100vh

Nunca force `height: 100vh` em uma capa! Se o usuário abrir a página em um dispositivo com tela reduzida ou fonte ampliada, o conteúdo transbordará sem que o usuário consiga rolar para ler.

A regra correta:
```css
.cover {
  display: flex;
  flex-direction: column;
  min-block-size: var(--cover-min-height, 100vh);
  padding: var(--space-m);
}

.cover > * {
  margin-block: var(--space-s);
}

/* O elemento central empurra tudo acima e abaixo com auto */
.cover > [data-centered] {
  margin-block: auto;
}

.cover > :first-child:not([data-centered]) {
  margin-block-start: 0;
}

.cover > :last-child:not([data-centered]) {
  margin-block-end: 0;
}
```
