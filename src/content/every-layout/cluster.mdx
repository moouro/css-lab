## 1. Conceito

Grupos de elementos heterogêneos em comprimento (como tags, links de navegação, migalhas de pão ou botões de rodapé) não cabem na rigidez de uma grade estática. O **Cluster** organiza itens no eixo horizontal de maneira fluida, permitindo que eles quebrem de linha conforme o espaço disponível acaba, sem exigir media queries.

## 2. O Problema Histórico e a Era do Gap

Antes do suporte amplo a `gap` no Flexbox (introduzido nativamente em 2021 em todos os motores), layouts desse tipo precisavam de técnicas complexas de margem negativa nos pais para compensar margens nos filhos, o que com frequência gerava barras de rolagem horizontal acidentais.

Hoje, a solução é limpa e declarativa:

```css
.cluster {
  display: flex;
  flex-wrap: wrap;
  gap: var(--cluster-space, var(--space-s));
  justify-content: var(--cluster-justify, flex-start);
  align-items: var(--cluster-align, center);
}
```

<AntiPattern
  badCode={`/* Antigo / Complexo: hack de margem negativa */\n.cluster > * {\n  margin: -0.5rem;\n}\n.cluster > * > * {\n  margin: 0.5rem;\n}`}
  goodCode={`/* Moderno e Resiliente */\n.cluster {\n  display: flex;\n  flex-wrap: wrap;\n  gap: var(--space-s);\n}`}
  explanation="O gap moderno elimina o risco de estouro de container e a necessidade de elementos 'wrappers' adicionais de isolamento de margem."
/>

## 3. Casos de Uso Comuns

- **Barras de Navegação:** Logo à esquerda e links à direita via `justify-content: space-between`. Quando a tela estreita, os links quebram naturalmente abaixo da marca sem media queries de breakpoint quebrem o cabeçalho.
- **Nuvem de Tags / Categorias:** Cada tag possui seu comprimento intrínseco.
- **Ações de Formulário:** Botões "Cancelar" e "Confirmar" mantêm espaçamento consistente.
