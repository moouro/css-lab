## 1. Conceito

Imagens e vídeos são elementos substituídos (*replaced elements*). Suas dimensões naturais vêm do arquivo codificado, fora do controle imediato do CSS. O **Frame** age como uma janela com proporção geométrica estrita através da qual a mídia é exibida sem distorção.

## 2. A Evolução: Do Hack de Padding ao aspect-ratio Nativo

Antes do suporte a `aspect-ratio` (agora amplamente suportado em todos os browsers), a web dependia do hack do padding percentual vertical (`padding-bottom: 56.25%` para 16:9).

Hoje, a especificação nativa simplifica radicalmente:

```css
.frame {
  aspect-ratio: var(--frame-ratio, 16 / 9);
  overflow: hidden;
  display: flex;
  justify-content: center;
  align-items: center;
}

.frame > img,
.frame > video {
  inline-size: 100%;
  block-size: 100%;
  object-fit: cover;
}
```

<Callout type="tip" title="Eliminação de CLS (Cumulative Layout Shift)">
  Ao declarar o `aspect-ratio` no container, o navegador reserva o espaço exato na tela antes mesmo que os bytes da imagem terminem de baixar pela rede, garantindo CLS zero!
</Callout>

<AntiPattern
  badCode={`/* Antigo / Complexo: hack de padding e posicionamento absoluto */\n.frame-wrapper {\n  position: relative;\n  padding-bottom: 56.25%;\n}\n.frame-wrapper > img {\n  position: absolute;\n  inset: 0;\n}`}
  goodCode={`/* Moderno e Declarativo */\n.frame {\n  aspect-ratio: 16 / 9;\n}\n.frame > img {\n  inline-size: 100%;\n  block-size: 100%;\n  object-fit: cover;\n}`}
  explanation="A propriedade aspect-ratio é nativa, elimina posicionamento absoluto desnecessário e funciona com qualquer proporção dinâmica via CSS Custom Properties."
