## 1. Conceito

Projetar uma grade no CSS moderno não significa desenhar uma tabela fixa de 12 colunas imaginárias. Significa dar ao navegador uma instrução declarativa: **"crie tantas colunas quantas couberem, desde que nenhuma seja mais estreita que X, e distribua o espaço restante igualmente entre elas"**.

## 2. A Fórmula Definitiva com min()

A fórmula clássica de Jen Simmons era:
```css
grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));
```

O problema dessa fórmula pura: se o container tiver menos de `250px` (ex: telas de relógio ou celulares antigos), a grade estoura horizontalmente porque `250px` era um limite mínimo rígido!

A solução moderna e blindada do *Every Layout* introduz a função `min()` no limite inferior do `minmax`:

```css
.grid {
  display: grid;
  grid-template-columns: repeat(
    auto-fill,
    minmax(min(var(--grid-min, 16rem), 100%), 1fr)
  );
  gap: var(--space-s);
}
```

Quando o container tem menos de `16rem`, `min(16rem, 100%)` retorna `100%`, fazendo o grid se comportar perfeitamente como uma coluna única segura!

<AntiPattern
