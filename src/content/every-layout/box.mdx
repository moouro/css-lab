## 1. Conceito

No CSS, tudo é uma caixa (*box*). A primitiva **Box** encapsula propriedades intrínsecas ao próprio elemento: preenchimento interno (**padding**), demarcação de borda e cores de fundo/texto.

<Callout type="tip" title="Axioma do Box">
  Se você não tem nada para colocar em uma caixa, você não precisa de uma caixa. O Box só existe para empacotar e delimitar conteúdo.
</Callout>

## 2. O Problema

Muitos desenvolvedores usam padding assimétrico (`padding: 10px 20px 30px 40px`) para empurrar elementos vizinhos. Isso viola a separação de conceitos:
- **Margin** é para afastar irmãos (pertence ao contexto, gerenciado por *Stack* ou *Cluster*).
- **Padding** é introspectivo: afasta o conteúdo das bordas internas da própria caixa.

<AntiPattern
  badCode={`/* Frágil: padding assimétrico para posicionar outros itens */\n.card-content {\n  padding-top: 40px;\n  padding-bottom: 10px;\n}`}
  goodCode={`/* Resiliente: padding uniforme derivado da escala */\n.box {\n  padding: var(--space-s);\n}`}
  explanation="Paddings irregulares desorganizam a escala visual e dificultam a reutilização do componente em novos contextos de design."
/>

## 3. Implementação Resiliente

```css
.box {
  padding: var(--space-s);
  border: var(--border-thin) solid var(--color-border);
  outline: var(--border-thin) solid transparent;
  outline-offset: calc(var(--border-thin) * -1);
  background-color: var(--color-surface);
}

.box * {
  color: inherit;
}

.box[data-invert] {
  color: var(--color-bg);
  background-color: var(--color-text);
}
```

<Callout type="important" title="Suporte a Windows High Contrast Mode">
  A propriedade `outline: var(--border-thin) solid transparent` associada ao `outline-offset` negativo garante que a caixa permaneça visível em modos de alto contraste do sistema operacional, sem alterar a largura calculada pelo modelo de caixa.
</Callout>
