## 1. Conceito

Elementos de fluxo textual e estrutural necessitam de respiro vertical para delimitar e organizar a leitura hierárquica. O **Stack** é o padrão algorítmico do *Every Layout* para gerenciar o ritmo vertical contínuo entre elementos, eliminando a necessidade de classes utilitárias repetitivas de margem em cada tag.

<Callout type="important" title="Princípio de Responsabilidade Única">
  O Stack possui uma única responsabilidade: **injetar espaçamento vertical entre elementos irmãos**. Ele nunca deve aplicar bordas, preenchimento interno ou alinhamentos horizontais.
</Callout>

## 2. O Problema

O método tradicional de aplicar `margin-bottom` a tags ou classes individuais é frágil e insensível ao contexto:

```css
p {
  margin-bottom: 1.5rem;
}
```

Quando esse parágrafo é o último elemento dentro de um container com padding (como um card ou dialog), a margem do parágrafo soma-se ao padding do container, distorcendo o equilíbrio visual (*margin doubling*).

<AntiPattern
  badCode={`/* Frágil: margem fixa no elemento */\nh2 { margin-bottom: 1rem; }\np { margin-bottom: 1.5rem; }\np:last-child { margin-bottom: 0; } /* Hack reativo */`}
  goodCode={`/* Resiliente: o container pai dita o ritmo */\n.stack > * + * {\n  margin-block-start: var(--space-s);\n}`}
  explanation="Margens aplicadas a elementos individuais criam acoplamento rígido. O combinador de irmãos adjacentes (* + *) garante que o primeiro elemento nunca tenha margem excedente e o último não sangre o container."
/>

## 3. A Solução

A técnica fundamental do livro é estilizar o **contexto** através do seletor *Lobotomized Owl* (`* + *`) com propriedades lógicas modernas (`margin-block-start`):

```css
.stack {
  display: flex;
  flex-direction: column;
  justify-content: flex-start;
}

.stack > * {
  margin-block: 0;
}

.stack > * + * {
  margin-block-start: var(--stack-space, 1.5rem);
}
```

### Por que propriedades lógicas?
O uso de `margin-block-start` em vez de `margin-top` garante conformidade nativa e automática para idiomas com diferentes modos de escrita (`vertical-lr` como Mongol, ou `horizontal-tb` padrão).

## 6. Variações Avançadas

### Divisão de Pilha (Split Stack)
Ao aplicar `margin-block-end: auto` no enésimo filho, flexbox empurra todos os itens subsequentes para a extremidade inferior da caixa disponível. É ideal para cartões com botões ou ações no rodapé:

```css
.stack > :nth-child(2) {
  margin-block-end: auto;
}
```
