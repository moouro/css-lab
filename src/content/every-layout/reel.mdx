## 1. Conceito

A web por padrão expande-se verticalmente. Rolar horizontalmente uma página inteira é uma falha de design grave (critério WCAG 1.4.10 Reflow). No entanto, seções **deliberadamente contidas** de rolagem horizontal (como vitrines de streaming de vídeo, prateleiras de produtos ou galerias de fotos) são extremamente ergonômicas em dispositivos de toque.

O **Reel** entrega um carrossel 100% nativo em CSS sem nenhuma biblioteca externa.

## 2. A Mecânica: Scroll Snap Nativo

```css
.reel {
  display: flex;
  overflow-x: auto;
  overflow-y: hidden;
  gap: var(--space-s);
  scroll-snap-type: x mandatory;
  scroll-padding-inline: var(--space-s);
  scrollbar-color: var(--color-border) transparent;
  -webkit-overflow-scrolling: touch;
}

.reel > * {
  flex-shrink: 0;
  flex-basis: var(--reel-item-width, auto);
  scroll-snap-align: start;
}
```
