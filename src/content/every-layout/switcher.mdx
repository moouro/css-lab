## 1. Conceito

Quando temos 3 ou 4 cartões de preço ou passos numerados, queremos que eles fiquem perfeitamente em uma linha horizontal. Se o espaço for insuficiente, não queremos um layout intermediário estranho com 2 itens em uma linha e 1 item gigante ocupando a linha de baixo.

Queremos que eles alternem diretamente de **1 linha horizontal** para **1 coluna vertical**. O **Switcher** resolve isso sem nenhuma media query.

## 2. A Fórmula "Holy Albatross"

A fórmula matemática criada por Heydon Pickering usa o tratamento de valores inválidos do CSS:

```css
.switcher {
  display: flex;
  flex-wrap: wrap;
  gap: var(--space-s);
}

.switcher > * {
  flex-grow: 1;
  flex-basis: calc((var(--switcher-threshold, 35rem) - 100%) * 999);
}
```

### Como funciona:
1. `100%` representa a largura atual do container pai.
2. Se o container tiver `40rem` (maior que o threshold de `35rem`):
   - `35rem - 40rem = -5rem`
   - `-5rem * 999 = -4995rem`
   - Uma `flex-basis` negativa é inválida no CSS, então o browser descarta e assume `0`.
   - Com `flex-basis: 0` e `flex-grow: 1`, todos os itens dividem o espaço horizontal em partes perfeitamente iguais!
3. Se o container tiver `30rem` (menor que o threshold de `35rem`):
   - `35rem - 30rem = +5rem`
   - `+5rem * 999 = +4995rem`
   - Cada item passa a pedir uma largura gigantesca, o que força imediatamente cada um a ocupar 100% da linha e empilhar verticalmente!

<Callout type="tip" title="O Ponto Alto do CSS Algorítmico">
  Esse é o exemplo mais puro de layout governado pelo browser: o autor apenas define uma restrição matemática (*threshold*) e o motor de renderização toma a decisão ideal em tempo real.
</Callout>
