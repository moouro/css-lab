## 1. Famílias Tipográficas

Priorizamos tipografias neutras, modernas e com legibilidade impecável para documentação técnica de código:

```css
:root {
  /* Tipografia para Interface e Conteúdo Editorial */
  --font-sans: "Inter", -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif;

  /* Tipografia para Código, Snippets e Tokens */
  --font-mono: "JetBrains Mono", ui-monospace, SFMono-Regular, "Cascadia Code", monospace;

  /* Axioma da Medida: Máximo de 65 caracteres por linha de leitura */
  --measure: 65ch;
}
```

## 2. A Escala Fluida (Major Third - 1.25)

Entre o menor smartphone (360px) e o monitor desktop (1200px):

```css
:root {
  --step--2: clamp(0.69rem, 0.65rem + 0.22vw, 0.8rem);     /* Badges e tooltips */
  --step--1: clamp(0.83rem, 0.77rem + 0.31vw, 1rem);      /* Metadados e código */
  --step-0:  clamp(1rem, 0.91rem + 0.43vw, 1.25rem);      /* Corpo do texto padrão */
  --step-1:  clamp(1.2rem, 1.07rem + 0.63vw, 1.56rem);    /* H4 */
  --step-2:  clamp(1.44rem, 1.26rem + 0.89vw, 1.95rem);   /* H3 */
  --step-3:  clamp(1.73rem, 1.48rem + 1.24vw, 2.44rem);   /* H2 */
  --step-4:  clamp(2.07rem, 1.73rem + 1.7vw, 3.05rem);    /* H1 */
  --step-5:  clamp(2.49rem, 2.03rem + 2.31vw, 3.82rem);   /* Hero Display */
}
```

## 3. Ritmo Vertical (Line Heights)

- Corpo do texto (`--step-0`): `line-height: 1.6` (conforto de leitura longa).
- Títulos médios (`--step-2`, `--step-3`): `line-height: 1.25` a `1.3`.
- Títulos grandes (`--step-4`, `--step-5`): `line-height: 1.1` a `1.15` (evita separação excessiva entre linhas).
