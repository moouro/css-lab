## 1. Escala Espacial Fluida

Nenhum espaçamento na plataforma é um valor arbitrário avulso. A escala de espaçamento escala suavemente com o viewport para que telas menores fiquem confortavelmente compactas e monitores ultrawide respirem com generosidade:

```css
:root {
  --space-3xs: clamp(0.25rem, 0.23rem + 0.11vw, 0.31rem);  /* 4px - 5px */
  --space-2xs: clamp(0.5rem, 0.46rem + 0.22vw, 0.63rem);   /* 8px - 10px */
  --space-xs:  clamp(0.75rem, 0.68rem + 0.33vw, 0.94rem);  /* 12px - 15px */
  --space-s:   clamp(1rem, 0.91rem + 0.43vw, 1.25rem);     /* 16px - 20px */
  --space-m:   clamp(1.5rem, 1.37rem + 0.65vw, 1.88rem);   /* 24px - 30px */
  --space-l:   clamp(2rem, 1.83rem + 0.87vw, 2.5rem);      /* 32px - 40px */
  --space-xl:  clamp(3rem, 2.74rem + 1.3vw, 3.75rem);      /* 48px - 60px */
  --space-2xl: clamp(4rem, 3.65rem + 1.74vw, 5rem);        /* 64px - 80px */
  --space-3xl: clamp(6rem, 5.48rem + 2.61vw, 7.5rem);      /* 96px - 120px */
}
```

## 2. Aplicação Canônica

- Micro-espaçamentos de botões e tags: `--space-3xs`, `--space-2xs`.
- Espaçamento padrão de cards e inputs: `--space-xs`, `--space-s`.
- Gaps de grids e separação de seções: `--space-m`, `--space-l`.
- Separação de blocos principais da página: `--space-xl`, `--space-2xl`.
